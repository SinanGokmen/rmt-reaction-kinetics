# DFT force-data reliability auditing

[Manuscript](dft_reliability/manuscript/main.pdf) · [Code and reproducibility](dft_reliability/README.md) · [arXiv source](dft_reliability/arxiv_source.zip) · [Submission instructions](dft_reliability/notes/SUBMIT_TR.md)

Sinan Gökmen, Department of Chemistry, Istanbul Technical University.

Current study: budget-aware reliability auditing of DFT force datasets. Two public paired molecular samples, explicit training-reference costs, physical consistency limits, and exploratory small-seed experiments. No universal RMT advantage or new DFT calculation is claimed.

The repository name predates this DFT study. Its earlier reaction-kinetics README remains available in Git history.

## Geometric deep learning

[Open the geometric deep learning experiment](geometric_deep_learning/)

A distance-based invariant graph network for force-error auditing, with code,
real-data results and numerical checks. Exploratory results improve recall on
Transition1x but worsen it on AIMNet2; no universal superiority is claimed.
